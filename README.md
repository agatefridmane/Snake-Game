I built a Snake game using Python’s Turtle module. The player steers the snake with W, A, S, and D. Each time the snake eats a piece of food, it grows by one segment, earns one point, and a new piece of food appears in a random location. The snake speeds up every five points.

If the snake hits a wall or its own body, it returns to the center, loses its extra segments, and starts again at zero points. The game displays the current score and saves the best score in high_score.txt so it carries over between sessions.

This project gave me practice handling keyboard input, making the snake’s body follow its head, detecting collisions, and saving data to a file.
